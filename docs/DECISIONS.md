# Decisions

One dated line per decision that still shapes the code, newest first. Add a line when a rule
changes; delete a line when the rule is gone. Superseded decisions are not kept here (git history
has them). Everything before July 2026 is summarised in the last lines.

- 2026-09-21 (v272): Home is read at a glance rather than read. A hero card holds the collection as one bar (reviewed, left, never brought in from Immich) with the photos left as the single large figure, its pace and the finish time; fixed cards follow for Advanced, Comparisons, Machines (state and lane dots, never a pace), Ratings (one stacked bar and five star cards, the five-star card carrying the 5% cap gauge) and the job. The coordinator's own release is on Home, beside the state. Each figure still appears once, nothing animates, and no card changes size with its numbers.
- 2026-09-21 (v271): Home is one panel — Work left, Library, Ratings, Machines, This job — and every figure in it appears exactly once, printed rather than animated, in a fixed row under a label that says what it means. It was five tiles, two of which answered "how much is left and when does it end" with different numbers and finish times eight times apart, and a third that drew the same throughput again with a third pace; there are no charts. The primary stage's remaining work is now every photograph that owes a review, not the generations already building: counting the in-flight window made the number sit at about five thousand all night while forty thousand photographs waited behind media staging.
- 2026-09-20: the release bump rewrites the keys it means (`STAR_IMAGE_TAG`, `image: star/...`, `STAR_WORKER_RELEASE_VERSION`), never a bare version token. A comment in the Apple worker compose file carried a version number and sat above the real key, so three bumps in a row rewrote the prose and left the Mac reporting v267 while running the v270 wheel — and `deploy` never listed it among the workers seen on the new release.
- 2026-09-20 (v270): work that can never succeed leaves the queue instead of waiting there. A comparison round that could not load one of its photographs is cancelled at once and the photograph's refusal is counted, whatever Immich's reason was, so the two-tries-then-never-again rule finally fires on every path (the round planner marked entries unavailable without counting, so the recovery pass handed the same photographs back every ten minutes for ever). Photographs Immich will not serve count as settled in "left in what you asked for", so a finished order reads zero instead of standing at twelve for ever. The Import form is always on screen with exactly one button that says what it will do ("Start on 50,000 photos", "Add 50,000 photos"); it used to disappear while a run was working or draining, so typing an amount led nowhere and the only way on was to cancel everything first.
- 2026-09-20 (v269): the amount to import is typed, never suggested — no default and no preset amounts — and it cannot exceed what is actually left, which the field prints beneath it (photographs Immich holds that Star has never taken in, or unfinished known photographs); the form stays on screen while a run is under way, so asking for more is the same form rather than a button with a number nobody chose. The five-star share is described as what it is: a cap at 5% of everything rated, the owner's own fives counted against it.
- 2026-09-20 (v268): asking for more photographs never stops the run — the count, the order and the all-photos choice stay editable and `add` raises the run's target, keeping what is already admitted; the Import screen answers how many are rated, how many are left of what was asked for, and how many of the Immich collection have never been brought in, instead of listing batches. A promotion is published against the photograph's current generation: a published rating is read from that generation only, so 192 photographs held a five-star place and stayed four-star, and the tier read 4.6% with every place filled.
- 2026-09-20 (v267): a parallel lane offers a model only when that model's measured lane allowance reaches it (`--parallel-model-lanes`, model=lanes pairs). Measured on the Mac with a different sheet in every lane: six Ministral lanes, and four Qwen3-VL comparison lanes where the fifth and sixth added no sheets an hour and grew swap. Comparisons had run on one lane, which is why the Mac looked three times slower than the NVIDIA worker at them. Measured the same day: the NVIDIA worker's 1,344-pixel sheet and the Mac's 4,096-pixel one rank the same photographs 0.92 alike with the same winner 13 times in 15, so the NVIDIA worker's coarser sheet is not weighted down and not made smaller.
- 2026-09-20 (v266): the bridge round, which keeps every band of contenders on one scale, looked for settled photographs among the waiting, comparing and ordered states, but the promotion pass leaves every settled photograph as a champion or a runner-up, so no bridge was ever found; it now takes a settled photograph of comparable strength whatever its tier state, and the tail finalizer had the same blind spot.
